# Perspective-*n*-Point alignment of plain radiographs and dental CBCT

PnP radiograph–CBCT registration using open-source tools (3D Slicer, Python, OpenCV). 

This directory groups the research workflow used for a case report (/Case Report) and one redistributable Python bundle for others who want to reuse the method (/PnP-Radiograph).

---

## Publication & citation

The forensic case report and methodology are described in a manuscript currently under review.
